# Adult dataset attribution

The archive in this directory is the Adult dataset distributed by the UCI Machine Learning Repository.

Becker, B. and Kohavi, R. (1996). *Adult* [Dataset]. UCI Machine Learning Repository. <https://doi.org/10.24432/C5XW20>.

The [UCI dataset page](https://archive.ics.uci.edu/dataset/2/adult) identifies the licence as [Creative Commons Attribution 4.0 International](https://creativecommons.org/licenses/by/4.0/) (CC BY 4.0). Repository code remains separately licensed under MIT.

`adult.zip` is retained as the unmodified raw ZIP distributed by UCI. Its locked SHA-256 is `7537312dd56c2b98035880805ce99e68183a30ee468aa5329d6df0fbb3cc21bb`; preprocessing reads members from that archive without rewriting it.
